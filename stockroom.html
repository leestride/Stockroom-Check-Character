How to use
1
Finding a check character
Type the full location code into the Code Lookup box above. The check character appears instantly. Codes are 4 characters long — two digits then two letters for standard locations, or a prefix letter (J, S, Z) followed by a digit and two letters.
2
Finding all locations with a check character
Use the Find Locations section. Select the NATO word (e.g. BRAVO) from the dropdown and optionally filter by location type. Tap Search to see all matching locations, grouped by aisle.
3
Location code formats
Standard: two digits + two letters (e.g. 43KA). Jewellery: J + digit + two letters (e.g. J6AA). Security: S + digit + two letters (e.g. S3AA). Bulk: Z + two digits + one letter (e.g. Z05R, voiced as Zero Five Bulk Romeo).
